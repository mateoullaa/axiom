# Strategy Creator

See [CLAUDE.md](CLAUDE.md) for the project overview and architecture.

## Setup

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Run the pre-flight check before making any change:

```
python init.py
```

Run the test suite:

```
pytest
```

## Frontend (once scaffolded)

```
cd frontend
npm install
npm run dev
```
